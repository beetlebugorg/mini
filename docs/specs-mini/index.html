Design

The screws are part of the face.

Four black socket head cap screws hold the front module in the sleeve. Their heads go through round ports in the grille and the strip. Each head is flush with the face.

Head ports

6.0 mm ports for 5.5 mm heads. A thin orange ring of the baffle shows around each head. A 0.5 mm chamfer at 45° prints face down with no support.

Snap catches

Four catches on each cover back. Each beam is one 0.5 mm line that bridges between two posts. It flexes along its printed lines, not across the layers.

Pockets

A lip at each pocket mouth holds the catch. The lip face is at 45°, so a pull releases the grille. A 0.05 mm preload holds the grille flat.

Build

Six steps.

  1. Prepare the sleeve. Remove the supports. Drill the front post holes. Install 8 inserts. Glue the feet.
  2. Mount the speakers. Drill or cut the baffle membranes. Install 8 inserts in the spacer frames. Fit the drivers with M3 × 5 screws.
  3. Fit the tray and the amplifier. Screw the tray to the baffle. Put the board on the rails. The volume control nut holds it.
  4. Install the front module. Push it into the sleeve. Install four M3 × 8 cap screws.
  5. Install the rear panel. Install four M3 × 6 cap screws.
  6. Fit the covers and the knob. Push the strip on, then the grille, until each set of four catches clicks.
